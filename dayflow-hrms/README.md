# DAYFLOW - Human Resource Management System (HRMS)

DAYFLOW is a full-stack Human Resource Management System (HRMS) featuring a **3D Sky-Blue Cloud & Rocket UI**. It provides role-based access control for Admins/HR and Employees with real-time attendance tracking, leave request workflows, payroll calculation, and interactive dashboard analytics.

---

## ⚡ Single Command Startup

To launch both the **Express Backend** (`http://localhost:5000`) and the **React Frontend** (`http://localhost:5173`) simultaneously:

```bash
cd dayflow-hrms
npm run dev
```

---

## 📝 User Registration & Authentication

The application is in a **clean state** with all demo users removed.

1. Navigate to `/register` to create a new **Employee** or **HR Admin** account.
2. Enter your Employee ID, Full Name, Email, Password, and Role.
3. Sign in on `/login` using your registered credentials.
